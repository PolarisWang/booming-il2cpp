# 构建环境要求

## 编译器要求

### Windows

| 项目 | 要求 |
|------|------|
| 编译器 | MSVC 14.44+ (Visual Studio 2022 17.14+) |
| 编译器路径 | `VC/Tools/MSVC/14.44.35207/bin/Hostx64/x64/cl.exe` |
| 编译器版本 | 19.44.35217 |
| 链接器路径 | `VC/Tools/MSVC/14.44.35207/bin/Hostx64/x64/link.exe` |
| Windows SDK | 10.0.22621.0+ |
| CMake | 3.25+ |
| C++ 标准 | C++17 |

> 注意：项目依赖 MSVC 默认的 `/MD` (MultiThreadedDLL) 运行时库。`CMAKE_MSVC_RUNTIME_LIBRARY` 不应手动设置。

### macOS

- Xcode 15+, macOS 13.0+ deployment target
- 架构：arm64 + x86_64 (universal binary)

### Android

- NDK (via `ANDROID_NDK_ROOT`), API 24, ABI arm64-v8a

### iOS

- Xcode (via `DEVELOPER_DIR`), iOS 16.0+ deployment target

## 构建工具链

工具链定义位于 `build/toolchains/`，通过 `CMakePresets.json` 关联：

| Preset | 宿主平台 | 目标平台 | 工具链文件 |
|--------|---------|---------|-----------|
| `windows-x64-reference` | Windows | Windows x64 | `build/toolchains/windows-x64-reference.cmake` |
| `macos-reference` | macOS | macOS arm64+x86_64 | `build/toolchains/macos-reference.cmake` |
| `android-arm64-smoke` | Windows | Android arm64 | `build/toolchains/android-arm64.cmake` |
| `ios-arm64-packaging` | macOS | iOS arm64 | `build/toolchains/ios-arm64.cmake` |
| `linux-x64-packaging` | Windows / macOS | Linux x64 | `build/toolchains/linux-x64.cmake` |

## 本地构建脚本

详见 [`统一入口脚本.md`](../04-工具与集成/统一入口脚本.md)：
- `run.ps1` / `run.sh` / `run.cmd` — 统一入口
- `run prepare` — 准备构建环境（CMake 按需安装）
- `run doctor` — 检查工具链完整性
