# test-driven-development

> 项目中的 TDD 基线，要求功能变更与 skill 变更都先有失败测试。

## 基本信息

- 分层：质量保障
- 项目职责：为实现改动与 skill 行为改动提供红绿重构纪律
- 实现路径：`.codex/skills/booming-code-test-driven-development/SKILL.md`
- 状态：`project`

## 项目规则

- 新增或增强 skill 时，先写失败测试再改 skill 文本
- skill 行为测试优先放在 `.codex/tests/claude-code/`
