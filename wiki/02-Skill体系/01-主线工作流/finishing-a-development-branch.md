# finishing-a-development-branch

> 项目中的开发收尾 skill，负责在主线执行完成后处理分支收尾。

## 基本信息

- 分层：主线工作流
- 项目职责：在 execution 已归档后，完成本地合并、提交与分支/worktree 收口
- 实现路径：`.codex/skills/dev-finishing-a-development-branch/SKILL.md`
- 状态：`active`

## 项目规则

- 只有执行记录已完成自动归档后，才进入本技能
- 本技能不负责活动任务守卫，也不负责 wiki 沉淀
- 本技能不再提供 PR / 保留分支 / 丢弃工作的多选分流，默认目标是本地合并&提交
- 如果归档步骤留下未提交改动，必须先在当前工作分支提交，再执行本地合并
- 本技能不自动 `git push`，远端写入是否需要由用户另行决定

## 最近变更

- `2026-04-02`：与 execution 自动归档顺序绑定。
- `2026-04-17`：改为固定本地合并与提交收口，不再提供四选一分支结束选项。
