# AutoTestGenerator: BCL 方法级自动测试生成管线

## 一句话摘要

从 BCL DLL 自动生成测试项目，覆盖 method-level `[Fact]`（带断言验证）/ `[Benchmark]`（零开销）/ `[HotUpdate]` 三型 subject，5 阶段管线执行：Scan → ValueGen → Probe → TestEmit → ProjectWrite。

## 关键结论

- 管线起点是目标 DLL 路径，终点是完整 dotnet 项目（`.csproj` + `Program.cs` + `AutoGenerated.cs` + `README.md`）
- 生成的 `[Fact]` subject 包含 `Assert.AreEqual` 断言，基于 probe 阶段捕获的确定性返回值
- 非确定性/纯 void 方法只生成 `[Benchmark]` subject
- 所有 subject 使用 `Chaos.TestFramework.Sdk` Assert API，带 `[Conditional("VERIFY")]` guard
- 批量生成入口：`./run-autotest-generator.sh --private --verify`

## 管线结构

| Phase | 类 | 职责 |
| --- | --- | --- |
| 1 Scan | `DllScanner` | MetadataLoadContext 扫描 DLL，提取 public method 签名，泛型具体化（`T` → `int`/`string`） |
| 2 ValueGen | `ValueGenerator` | 产生 3-5 组参数值（boundary + default + smart + collection variant + AutoFixture） |
| 3 Probe | `ProbeEmitter` | 3-pass build+run，`JsonSerializer.Serialize` 捕获返回值/异常，majority-vote 判确定性 |
| 4 TestEmit | `TestEmitter` | 生成 `[Fact]` + `[Benchmark]` + `[HotUpdate]` 三型 C# 方法代码 |
| 5 ProjectWrite | `ProjectWriter` | 输出 `.csproj` / `Program.cs` / `AutoGenerated.cs` / `README.md` |

完整列表见 `ValueGenerator.cs:14-45`。

## NullGuard 安全表达式

`ValueGenerator.NullGuardSafeDefaults` 字典为常见接口/抽象类型提供非 null 工厂表达式，避免 `ArgumentNullException`：

| 接口/抽象类型 | 工厂表达式 |
| --- | --- |
| `IList<T>` | `Array.Empty<T>()` |
| `IDictionary<K,V>` | `new Dictionary<K,V>()` |
| `ISet<T>` | `new HashSet<T>()` |
| `IEnumerable<T>` | `Enumerable.Empty<T>()` |
| `IComparer<T>` | `Comparer<T>.Default` |
| `Stream` | `Stream.Null` |
| `HashAlgorithm` | `SHA256.Create()` |
| `RSA` | `RSA.Create()` |

## Assert 集合结构比较

`Assert.AreEqual<T>` 在 `Chaos.TestFramework.Sdk` 中增加运行时 IEnumerable 结构比较：

- 当 expected 和 actual 均非 null、非 string 且均实现 `IEnumerable` 时，逐元素比较
- 元素使用 `EqualityComparer<object?>.Default` 比较
- 长度差异或元素不匹配 ⇒ `[ASSERT FAIL]`
- 非集合类型保持原有 `EqualityComparer<T>.Default` 行为

## 批量运行

```bash
# 全量 CoreLib 类型 + verify 验证
./run-autotest-generator.sh --private --verify

# 单 DLL 所有 public 类型
./run-autotest-generator.sh --dll <path>

# 查看已知 DLL 列表
./run-autotest-generator.sh --list
```

## 维护约定

- 新增 BCL 类型到 `run-autotest-generator.sh` `PRIVATE_TYPES` 时同步覆盖范围
- `BoundaryValues` / `NullGuardSafeDefaults` 新增条目后运行 `--private --verify` 验证
- 修改 `Assert.cs` 时必须确保不破坏原始类型（int/string/double）的相等性
- 新增 probe 阶段捕获的类型必须在 `CSharpSerializer.DeserializeToExpression` 中有对应反序列化逻辑
