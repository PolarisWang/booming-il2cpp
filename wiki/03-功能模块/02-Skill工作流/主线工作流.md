# 主线工作流

项目主线是：

`using-booming -> active-execution-guard -> brainstorming -> roadmap / writing-plans -> executing-plans / subagent-driven-development -> finishing-a-development-branch`

## 关键约束

- 活动任务守卫先于所有其他 skill
- `writing-plans` 负责为执行阶段准备设计路径和知识沉淀目标
- `roadmap` 负责多阶段复杂事项的父任务拆分
- 执行阶段负责维护 `STATUS.md`、`ACTIVE.md` 与目录终态
- wiki 维护在任务完成后进行
