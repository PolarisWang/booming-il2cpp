# 主线工作流

项目主线是：

`using-booming -> active-execution-guard -> brainstorming -> writing-plans -> executing-plans / subagent-driven-development -> finishing-a-development-branch`

## 关键约束

- 活动计划守卫先于所有其他 skill
- `writing-plans` 负责为执行阶段准备设计路径和知识沉淀目标
- 执行阶段负责维护 `CURRENT.md` 和 history
- wiki 维护在任务完成后进行
