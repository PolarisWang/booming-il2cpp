# COM 互操作测试与验证

## 测试体系

COM 互操作测试位于 `testing/foundation-dll/System.Private.CoreLib/` 目录。

### ccw-basic 家族

**目录**: `ccw-basic/`
**状态**: ✅ 完成 (V3)

测试 COM Callable Wrapper 的核心功能：

| Subject | 测试内容 | 验证点 |
|---------|---------|--------|
| Subject_0 | ISimpleMath.Add 通过 CCW 分发 | 方法调用的正确性 |
| Subject_1 | ISimpleMath.Multiply 通过 CCW 分发 | 方法调用的正确性 |
| Subject_2 | IConstantValue.GetValue 通过 CCW 分发 | 方法调用的正确性 |
| Subject_3 | DualInterfaceImpl (实现两个接口) | 多接口分发的一致性 |

**方法**: 每次调用通过 C# 的接口分发调用两次，比较结果一致性。

### rcw-basic 家族

**目录**: `rcw-basic/`
**状态**: ✅ 完成 (V2)

测试 Runtime Callable Wrapper 的 round-trip 能力和方法分发：

| Subject | 测试内容 | 验证点 |
|---------|---------|--------|
| Subject_0 | Round-trip identity | CCW IUnknown* == RCW identity_unknown |
| Subject_1 | Round-trip QI | 通过 RCW QI 返回非空且 != identity_unknown |
| Subject_2 | RCW vtable 方法调用 | 通过 RCW handle 调用 COM 方法（MarshalCallComMethod） |
| Subject_3 | 直通 vtable 调用 | 通过原始 COM 指针调用方法（MarshalCallDirectComMethod） |

**流程**: 托管→创建 CCW→获取 IUnknown*→包装为 RCW→QI 验证→方法分发→释放

### dispatch-basic 家族

**目录**: `dispatch-basic/`
**状态**: ✅ 完成 (V2)

测试 IDispatch 晚期绑定能力：

| Subject | 测试内容 | 验证点 |
|---------|---------|--------|
| Subject_0 | IDispatch QI | 通过 QI 获取 IDispatch 接口 |
| Subject_1 | GetIDsOfNames | 按名称查找方法 DISPID |
| Subject_2 | Invoke | 通过 DISPID 调用方法 |

**流程**: 托管→创建 CCW→QI for IDispatch→GetIDsOfNames→Invoke→验证结果

### error-info-basic 家族

**目录**: `error-info-basic/`
**状态**: ✅ 完成 (V1)

测试 COM IErrorInfo 集成和错误信息传播：

| Subject | 测试内容 | 验证点 |
|---------|---------|--------|
| Subject_0 | IErrorInfo 格式正确的 HRESULT 异常传播 | COMException 携带 description |
| Subject_1 | IErrorInfo 未设置时回退 hex 格式 | Fallback 行为正确 |
| Subject_2 | GetErrorInfo 跨线程安全 | TLS 隔离 |

**流程**: 模拟 COM 方法返回失败 HRESULT→运行时调用 GetErrorInfo 获取描述→验证异常类型和信息

## COM 套间测试

COM 套间支持（STA/MTA）通过 `run foundation-dll verify-family --family com-apartment-basic` 验证，覆盖 CoInitializeEx、套间类型查询、STA message pump 等场景。

## SAFEARRAY 测试

SAFEARRAY marshaling 通过 struct marshaling 管线验证，覆盖 SafeArrayCreate/SafeArrayAccessData/SafeArrayUnaccessData/SafeArrayDestroy 四个 OLEAUT32 thunk 函数，以及 Variant VT_ARRAY 的 boxing/unboxing 路径。

## 运行方法

```bash
# 构建管线
dotnet build src/managed/Chaos.IL2CPP.Pipeline

# 构建原生运行时
cmake --build artifacts/presets/debug --target chaos_runtime_core

# 运行全管线验证（生成 codegen、编译、执行、校验）
run foundation-dll verify-family --family ccw-basic
run foundation-dll verify-family --family rcw-basic
run foundation-dll verify-family --family dispatch-basic
run foundation-dll verify-family --family error-info-basic
run foundation-dll verify-family --family com-apartment-basic
```
