# COM 互操作代码生成

## 管线概览

```
Metadata (IL) → NativeAotLoweringPlanner → Scriban Template → Generated .cpp
```

## Planner 阶段

### NativeAotLoweringPlanner.ObjectModelUtilities.cs

`CollectComInterfaceVtableData` 方法：

1. 遍历所有 COM 接口类型声明
2. 为每个接口创建 `ComInterfaceVtableInfo`
3. 收集接口的方法列表，按 metadata token 排序
4. 计算 `stable_id`（FNV-1a hash of GUID）
5. 传递给 Scriban 模板

### 数据结构

```csharp
internal sealed record ComInterfaceVtableInfo(
    string Guid,
    CHAOS_IL2CPP_UINT64 StableId,
    ComInterfaceMethodSlot[] Methods
);

internal sealed record ComInterfaceMethodSlot(
    uint Token,
    string NativeSymbol
);
```

### ComInterfaceVtableInfo 的收集过程

```
MetadataRegistrationArtifact
    → MetadataTokenLookup (查找方法的 metadata token)
    → methodsBySubjectId (按 subject id 分组的方法列表)
    → 过滤出 declaring type 匹配 COM 接口的方法
    → 按 metadata token 排序
    → 构建 ComInterfaceVtableInfo
```

### 接口类型收集

`CollectInterfaceTypeSubjectIds` 遍历所有方法的指令，收集被引用的接口类型：

- 检查 `TargetReference` 中的 `Type` 和 `Method/Field/Event` 引用的 declaring type
- 过滤出 `TypeShape == InterfaceType` 的类型
- 用于 vtable 长度计算和 COM vtable 分发决策

### COM 方法可达性增强

由于 COM 接口方法通过 vtable 分发而非直接 call/callvirt 指令调用，静态调用图分析无法发现这些方法。两处增强：

1. **InvocationPlanning.cs** — `ResolveComVtableReachableMethods` 同时解析直接调用目标和接口分发目标（`ResolveInterfaceDispatchTargets`）
2. **NativeAotLoweringPlanner.cs** — 在 `CollectReachableMethods` 之后，为实现了 COM 接口的类型补充其所有方法到 `methodsForLowering`；在 `ComputeAotReachableSubjectIds` 之后，将这些方法标记为 AOT 可达（生成完整 C++ 函数体）

## 模板阶段

### NativeAot.HotpatchTable.cpp.scriban

CCW 相关的模板输出：

#### GUID 常量

```cpp
static constexpr CHAOS_IL2CPP_UINT8 s_ccw_guid_X[16] = { bytes... };
```

#### 方法 Thunk (每接口方法一个)

```cpp
extern "C" void CcwThunk_X_N(void* self) {
    auto* entry_ccw = CcwFromInterface(self);
    CcwDispatchMethod(entry_ccw, stable_id, N);
}
```

#### Vtable (3 IUnknown + N 方法槽 / 7 IDispatch + N 方法槽)

```cpp
static void* s_ccw_vtable_X[M] = {
    &CcwQueryInterface,
    &CcwAddRef,
    &CcwRelease,
    &CcwThunk_X_0,
    &CcwThunk_X_1,
    // ...
};
```

对于 IDispatch 接口，vtable 前 7 个槽为：

```cpp
static void* s_ccw_vtable_X[M] = {
    &CcwQueryInterface,      // IUnknown
    &CcwAddRef,              // IUnknown
    &CcwRelease,             // IUnknown
    &CcwGetTypeInfoCount,    // IDispatch
    &CcwGetTypeInfo,         // IDispatch
    &CcwGetIDsOfNames,       // IDispatch
    &CcwInvoke,              // IDispatch
    &CcwThunk_X_0,           // 接口方法
    // ...
};
```

#### Factory 函数

```cpp
extern "C" CHAOS_IL2CPP_INTPTR CreateCcwFor_X(void* obj, void* state) {
    auto* ccw = CreateCcw(obj, state);
    if (ccw) RegisterCcwInterface(ccw, guid, vtable);
    return ccw;
}
```

#### 静态初始化 (Factory 注册)

```cpp
unsigned int s_ccw_factory_registered_X = []() {
    RegisterCcwFactory(s_ccw_guid_X, CreateCcwFor_X);
    return 1u;
}();
```
