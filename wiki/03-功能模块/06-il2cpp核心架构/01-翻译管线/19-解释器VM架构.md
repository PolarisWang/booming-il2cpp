# 解释器 VM 架构

## 核心职责

基于栈的 IL 解释器，运行时执行 IR 指令。是热更新路径的 fallback 执行引擎。

## IR Opcode（53 + 1 个）

| 类别 | Opcode 集合 |
|------|-----------|
| 加载 | `LdcI4`, `LdcI8`, `LdcR4`, `LdcR8`, `Ldstr`, `Ldnull`, `Ldarg`, `Ldloc`, `Ldloca`, `Ldind`, `Ldobj` |
| 存储 | `Starg`, `Stloc`, `Stind`, `Stobj` |
| 字段 | `Ldfld`, `Stfld`, `Ldsfld`, `Stsfld` |
| 数组 | `NewArr`, `Ldlen`, `Ldelem`, `Stelem`, `Ldelema` |
| 调用 | `Call`, `Callvirt`, `NewObj`, `Ldftn`, `Ldvirtftn`, `Calli`, `Ret` |
| 对象 | `Box`, `Unbox`, `CastClass`, `IsInst` |
| 类型转换 | `ConvI4`, `ConvI8`, `ConvR4`, `ConvR8`, `ConvOvf` |
| 分支 | `Br`, `Brtrue`, `Brfalse`, conditional branches |
| 比较 | `Ceq`, `Cgt`, `Clt` |
| 算术 | `Add`, `Sub`, `Mul`, `Div`, `Rem`, `Neg`, `And`, `Or`, `Xor`, `Not` |
| 异常 | `Throw`, `Rethrow`, `Leave`, `EndFinally`, `EndFilter` |

## 关键类型

| 类型 | 说明 |
|------|------|
| `InterpreterValue` | 带 tag 的联合体（i32/i64/f32/f64/obj），含类型工厂方法 |
| `IRInstruction` | opcode + operand index + immediates + branch target + string operand |
| `IRMethod` | IR 指令向量 |
| `ExecutionFrame` | 参数 + 局部变量 + 求值栈的独立向量 |
| `ExecutionResult` | 执行结果（正常/异常） |

## 执行模型

```
IRMethod → InterpreterVM::Execute(IRMethod, ExecutionFrame) → ExecutionResult
```

- 纯栈机——无寄存器
- InterpreterValue 带 tag 跟踪类型
- 支持完整的 EH（throw/rethrow/leave/endfinally/endfilter）
- 对象模型基于堆分配（ObjectStorage、ArrayStorage、BoxedValue）

## 与热更新的关系

- 热更新加载补丁 IL 后，可编译为 IRMethod
- 通过 `method_replacement` 表将 AOT 方法重定向到解释器执行
- 解释器作为 fallback 执行引擎
