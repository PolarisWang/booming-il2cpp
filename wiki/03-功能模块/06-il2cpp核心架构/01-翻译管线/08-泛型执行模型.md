# 泛型执行模型

## GenericContextShapeKind

3 种泛型上下文形状：

| Kind | 描述 | 存储方式 |
|------|------|---------|
| None | 非泛型方法 | 不需要上下文 |
| ByStaticStorage | 封闭泛型实例化 | 全局静态存储 |
| ByContext | 开放泛型（运行时决策） | 运行时传递 context 参数 |

## 封闭泛型实例化

- 封闭泛型类型/方法在 AOT 编译期完全实例化
- 每个封闭实例化生成独立的 C++ 函数
- Method handle 通过 `resolve_method_by_token` 解析

## 封闭泛型 Method Handle

- 泛型方法在编译期展开为具体特化版本
- 每个特化版本有独立的函数指针
- 通过 `GenericContext` 在运行时区分不同实例化

## 约束

- 不允许在运行时动态实例化开放泛型
- 泛型共享（generic sharing）不做，每个封闭实例化独立生成
- 泛型虚方法需要完整的类型 hierarchy 展开

## 运行时注册与解析

C++ 端 `generic_context` 子系统处理泛型实例化的运行时注册和查询：

### 关键函数

| 函数 | 说明 |
|------|------|
| `RegisterGenericInstantiation(open_token, type_args...)` | 开放泛型 token + 类型参数 → 封闭 token |
| `RegisterMethodGenericContext(method_token, class_type_args, method_type_args)` | 关联类型参数和方法参数 |
| `GetGenericContextForMethod(method_token)` | 查询方法的泛型上下文 |
| `GetClassTypeArg(context, index)` | 从上下文中查询类类型参数 |
| `GetMethodTypeArg(context, index)` | 从上下文中查询方法类型参数 |

### 与 codegen 的关系

- 对 AOT 编译中遇到的每个封闭泛型实例化（如 `List<int>`），codegen 发射 `RegisterGenericInstantiation` 调用
- 对泛型方法实例化，发射 `RegisterMethodGenericContext`
- 运行时 `typeof(T)` 或 `MakeGenericMethod` 通过这些注册表解析类型参数，无需重新解析元数据

### 位置

- 模块: `chaos_runtime_core`
- 文件: `src/native/runtime-core/generic_context.*`
