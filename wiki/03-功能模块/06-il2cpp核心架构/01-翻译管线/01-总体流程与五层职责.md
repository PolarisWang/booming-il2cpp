# 总体流程与五层职责

## 翻译管线总览

```
IL Assembly
   │
   ▼
┌─────────┐     ┌──────────────┐     ┌────────┐     ┌─────────┐     ┌─────────┐
│  Loader  │────▶│SemanticWorld │────▶│ Linker │────▶│ CodeGen │────▶│ Emitter │
└─────────┘     └──────────────┘     └────────┘     └─────────┘     └─────────┘
                                                           │              │
                                                           ▼              ▼
                                                     LoweringPlan    C++ Output
```

## 五层职责速查

| 层次 | 输入 | 输出 | 核心职责 |
|------|------|------|---------|
| Loader | .dll/.exe | AotCoreIrArtifact | 读出 metadata、raw IL、member records |
| SemanticWorld | AotCoreIrArtifact | canonical semantic objects + operation stream + capability hints | 语义归一化 |
| Linker | semantic objects | retained world + external dependencies + reasons | 裁减未使用类型/方法，标记依赖理由 |
| CodeGen | retained world | LoweringPlan | 选 lowering family、组装 plan |
| Emitter | LoweringPlan | .cpp 文件 | 消费 plan 渲染 C++ |

## 调用链入口

`NativeAotLoweringPlanner` 是 CodeGen 层中央编排器，内部通过 C# partial class 分布在 20+ 文件中。Emitter 通过 `EmissionOrder` 驱动，按 `SemanticShape` 分派到对应 `Emit*` 方法。
