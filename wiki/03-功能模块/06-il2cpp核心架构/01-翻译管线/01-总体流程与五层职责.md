# 总体流程与五层职责

## 翻译管线总览

```
IL Assembly
   │
   ▼
┌─────────┐     ┌──────────────┐     ┌────────┐     ┌────────────────┐     ┌──────────┐
│  Loader  │────▶│SemanticWorld │────▶│ Linker │────▶│ MetadataWriter │────▶│ CodeGen  │
└─────────┘     └──────────────┘     └────────┘     └────────────────┘     └──────────┘
                                                                                 │
                                                                                 ▼
                                                                           LoweringPlan
                                                                                 │
                                                                            (post-pipeline)
                                                                                 ▼
                                                                           ┌─────────┐
                                                                           │ Emitter │
                                                                           └─────────┘
                                                                                 │
                                                                                 ▼
                                                                           .cpp 文件
```

**关键区别**：`MetadataWriter` 是管线内的第四阶段，产出 `MetadataRegistration`供启动引导使用；`Emitter` 是**管线后阶段**，消费 `LoweringPlan` 渲染 C++，独立运行于 `NativeAotEmitter`。PipelinePlan 的 `Stages` 列表明确包含这五个阶段。

## 五层职责速查

| 层次 | 输入 | 输出 | 核心职责 |
|------|------|------|---------|
| Loader | .dll/.exe | AotCoreIrArtifact | 读出 metadata、raw IL、member records |
| SemanticWorld | AotCoreIrArtifact | canonical semantic objects + operation stream + capability hints | 语义归一化 |
| Linker | semantic objects | retained world + external dependencies + reasons | 裁减未使用类型/方法，标记依赖理由 |
| MetadataWriter | linked world | MetadataRegistrationV0 | 产出 MetadataRegistration（泛型类型/方法表 + 泛型参数约束等），供 BootstrapRuntime 消费 |
| CodeGen | linked world + MetadataRegistration | LoweringPlan | 选 lowering family、组装 plan |

## 调用链入口

`PipelinePlan`（`src/managed/Chaos.IL2CPP.Pipeline/PipelinePlan.cs`）编排五阶段顺序调用：

```csharp
var loadedWorld = _loader.LoadMultiple(request);
var semanticWorld = _semanticWorld.Build(loadedWorld);
var linkedWorld = _linker.Link(semanticWorld);
var metadataWriterOutput = _metadataWriter.Write(linkedWorld);
return _codeGen.Generate(request, linkedWorld, metadataWriterOutput);
```

`NativeAotLoweringPlanner` 是 CodeGen 层中央编排器，内部通过 C# partial class 分布在 24 个文件中。

### Emitter（管线后阶段）

Emitter 不在 PipelinePlan 内，由 Driver 在管线完成后单独调用：

```csharp
// DriverEntry.Run(NativeAotRequest) 中:
var emitter = new NativeAotEmitter();
var result = emitter.Generate(request);
```

发射器读取 LoweringPlan + MetadataRegistration 等产物，通过 Scriban 模板渲染 `.cpp` 文件。Emitter 本身也分布在多个 partial 文件中，包括 `NativeAotEmitter.cs` 主入口和 `NativeReferenceProofEmitter.*.cs` 引用证明系。
