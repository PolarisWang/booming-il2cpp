# 静态初始化模型

## 核心模式

使用 `std::call_once` + `std::once_flag` 实现线程安全的静态初始化：

```cpp
static std::once_flag s_flag;
static SomeType* s_instance = nullptr;

std::call_once(s_flag, []() {
    s_instance = new SomeType(...);
});
```

## 降级策略

| 场景 | 策略 |
|------|------|
| 无 static constructor | 无初始化开销 |
| 简单 static field init | 编译期常量折叠 |
| 复杂 static constructor (cctor) | `std::call_once` 惰性初始化 |
| 循环依赖 cctor | 运行时检测 + 回退 |

## 约束

- 不允许在 cctor 中分配托管对象（可能触发嵌套 cctor）
- cctor 降级策略参见 `02-翻译路径参考/06-静态初始化与对象相等性翻译表.md`
- AOT 编译期可计算的值在编译期完成，不生成运行时初始化代码
