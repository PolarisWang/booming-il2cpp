# 字符串表运行时

## 核心职责

全局字符串驻留表。将 64-bit StringId 映射到 UTF-8 StringView，同时支持 AOT 预计算和运行时注册。

## 关键类型

| 类型 | 说明 |
|------|------|
| `StringId` | uint64，bit63 标记的字符串 ID |
| `StringView` | pointer + byte count |
| `StringEntry` | id + pointer + count，用于 AOT 批量初始化 |

## 关键函数

| 函数 | 说明 |
|------|------|
| `InitializeFromAot(entries[])` | 批量加载 AOT 数据段中预计算的字符串条目 |
| `Resolve(id)` | StringId → StringView 查找 |
| `Register(id, str, domain_id)` | 注册新字符串，按域跟踪 |
| `Intern(str)` | 去重注册（无域） |
| `UnregisterDomain(domain_id)` | 批量移除某域的所有字符串 |

## 运行时查找算法

- 先检查动态条目（热更新注册的字符串）
- 然后对 AOT 表进行二分查找

## 与 codegen 的关系

- AOT 编译器为所有字符串字面量和元数据名称预计算 StringId，发射为 `StringEntry[]` 数组
- 生成代码中的 ldstr、反射名称查找等操作使用 `Resolve(id)` 而非嵌入原始字符数据
- 热更新代码可在运行时调用 `Register` 注册新字符串
- 域卸载时通过 `UnregisterDomain` 批量释放
