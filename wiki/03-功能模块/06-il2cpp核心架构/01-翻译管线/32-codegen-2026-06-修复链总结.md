# Codegen 2026-06 修复链总结

> **日期**: 2026-06-23
> **涉及 commit**: `8ed8d3dfc` ~ `1c8cbe3cd`（11 个提交）
> **效果**: C2660 错误 429→2, C2061/C2039 类型错误归零

## 修复的问题

### 1. 分区删除导致类型声明缺失

**根因**: commit `8d7592864` 删除了 `System.Collections.NonGeneric` 分区文件，但 `System.Collections/global-ns` chunk 仍引用 NonGeneric 类型。TPG codegen 不为跨程序集类型生成结构体定义。

**修复**: 
- 恢复 NonGeneric 分区文件
- 清理 `System.Collections/_dll/namespace-partition.json`（totalChunks=0）
- 从 hephaestus 缓存恢复 codegen 输出

### 2. CMakeLists 相对路径导致链接失败

**根因**: TPG 生成 CMakeLists.txt 时使用 `GetRelativePath()` 产生相对路径（`codegen`），cmake 解析为 `build/codegen/` 导致 LNK1181。

**修复**: `ProjectModel.cs` 改用绝对路径。

### 3. object_stubs.cpp 重复定义

**根因**: 本地 `object_stubs.cpp` 被 GLOB 捕获，与 SDK 版本重复编译。

**修复**: 添加到 `TestProject.CMakeLists.txt.scriban` 的 REMOVE_ITEM 列表。

### 4. subject-only IR lowering 类型缺失

**根因**: commit `3be973040` 将 IR lowering 改为 subject-only 模式，只 lower subject 方法 + 直接 callee。嵌套类型（`Queue+QueueEnumerator`）的 methods 不在 IR 中，codegen 无法为它们生成类型声明。

**修复链**：
1. `ObjectModelEmission.cs` 添加 callee-based type discovery（从 `instruction.Callee` 提取声明类型）
2. 反射元数据 fallback（从 `_reflectionMemberSupport.FieldEntries` 补充类型）
3. **ABI slot 扫描**（核心修复）：遍历 `_methodsBySubjectId.Values` 中所有方法，捕获返回值类型、参数类型、异常类型、声明类型
4. `_trackTypeRef` 改用 `TrackReferenceType` 确保基类链正确解析

### 5. C2660 函数参数不传递

**根因**: catch-all external runtime helper 使用 `Array.Empty<AotCoreIrAbiSlotArtifact>()`（0 参数），导致函数调用生成 `func()` 空括号而非实际参数。

**修复**:
1. `ExternalRuntimeHelpers.cs` catch-all 使用 `InferParameterCountFromSubjectId` + `CreateLegacyAbiParameterSlots` 计算实际参数数量
2. `ResolveDirectInvocationTarget` 添加 dispatch table fallthrough（当 catch-all 返回 0 参数但指令有参数时）

### 6. chaos_object_equals 未声明

**根因**: `EmitObjectEqualityHelpers` 在 page 0 定义了 `chaos_object_equals`，但 page files 的 `extern` 声明缺失。

**修复**: `BuildTypeDeclarationsCode` 添加 `extern bool chaos_object_equals(...)` 声明。

## 架构要点

### Codegen 数据流

```
linkedWorld.Methods        ← 所有方法的 IL
    ↓ AotCoreIrLowering
aotCoreIr.Methods           ← 所有方法降级后（含 QueueEnumerator）
    ↓ NativeAotLoweringPlanner.Create
methodsForLowering          ← subject 方法 + 直接 callees（QueueEnumerator 被过滤）
_methodsBySubjectId         ← 仍包含所有方法（含 ABI metadata）
    ↓ EmitObjectModelDeclarations
reachableMethods (=methodsForLowering) → 主扫描（按指令）
_methodsBySubjectId.Values  → ABI slot 扫描（按方法签名）
```

### 关键文件

| 文件 | 功能 |
|------|------|
| `ObjectModelEmission.cs` | 类型发现 + 结构体定义发射 |
| `Methods.Remaining.cs` | `BuildTypeDeclarationsCode` 共享头文件生成 |
| `Methods.cs` | subject 方法选择 + reachability BFS |
| `ExternalRuntimeHelpers.cs` | catch-all 外部运行时 helper |
| `InvocationPlanning.Dispatch.Interface.cs` | 调用目标解析 + dispatch table |
| `ProjectModel.cs` | Scriban CMakeLists 模板模型 |
| `AotCoreIrLowering.cs` | IR 降级（无 subject 过滤）|
