# 热更新架构

## 核心职责

提供运行时加载/卸载热更新补丁包的能力，包括程序集元数据加载、方法替换、内存域生命周期管理。

## 热更新包加载

### HotUpdatePackageHandle

补丁包的运行时表示：

| 字段 | 说明 |
|------|------|
| `assembly_image` | 程序集 IL 字节和元数据 |
| `metadata_image` | 补充元数据镜像 |
| `package_id` | 包唯一标识 |
| `target_aot_version` | 目标宿主版本（用于兼容性检查） |
| `assembly_name` | 程序集名称 |
| `domain_id` | 热更新绑定的内存域 ID |
| `module_id` | GenericContextRegistry 模块 ID（>0，用于按模块清理泛型注册） |
| `loaded` | 是否已加载 |

## 泛型上下文注册

HotUpdate 包可能引入新的泛型类型/方法实例化。包加载时需要注册其泛型上下文：

```cpp
// 从补充元数据中构造 ModuleGenericRegistrationV0
// module_id 必须与 HotUpdatePackageHandle.module_id 一致
RegisterHotUpdateModuleGenerics(&registration_data);
```

- 注册流程：token → handle 解析 → 填充 GenericContextRegistry
- 卸载时自动清理：`UnregisterModuleGenerics(module_id)` 批量删除该包的所有泛型条目

### 包生命周期

| 阶段 | 函数 | 说明 |
|------|------|------|
| 加载 | `LoadHotUpdatePackage()` | 解析 `package.manifest.json`，加载 assembly/metadata image，分配 `module_id`（原子计数器），注册内存域 |
| 泛型注册 | `RegisterHotUpdateModuleGenerics()` | 注册包的泛型类型/方法实例化到 GenericContextRegistry，使用 `module_id` 索引 |
| 资源加载 | `LoadAssemblyImageFromPath()` | 从磁盘加载程序集 IL 字节 |
| 元数据加载 | `LoadSupplementalMetadataFromPath()` | 从磁盘加载补充元数据 |
| 卸载 | `UnloadHotUpdatePackage()` | 先 `UnregisterModuleGenerics(module_id)` 清理泛型注册，再注销字符串表、销毁内存域堆、释放 image |

### 卸载顺序（必须）

```
UnloadHotUpdatePackage:
  1. UnregisterModuleGenerics(module_id)
     → 从 by_open_type 和 by_method_token 中删除该模块所有条目
     → 释放关联的 RuntimeInstantiatedType 堆内存
  2. UnregisterDomain(domain_id)     // 清理字符串表
  3. UnregisterMemoryDomain(domain_id)  // 销毁内存域堆
  4. ReleaseAssemblyImage / ReleaseSupplementalMetadataImage
  5. 释放 DuplicateCString 字段
```

卸载必须先清理泛型注册（步骤 1），再释放元数据内存（步骤 4），因为泛型条目引用了 `TypeInfoHandle` 指向的反射描述符。

## 方法替换

### MethodReplacementEntry

| 字段 | 说明 |
|------|------|
| `method_token` | 方法标识 token |
| `original_pointer` | 原始 AOT 编译函数指针（支持安全回退） |
| `replacement_thunk` | 替换后的跳板函数指针 |
| `active` | 是否激活 |

### 替换操作

| 函数 | 说明 |
|------|------|
| `Register(token, thunk)` | 为指定 token 安装替换跳板 |
| `Revert(token)` | 移除单个替换 |
| `RevertAll()` | 清除所有替换 |
| `Resolve(token)` | 查询当前替换（返回替换指针或 nullptr） |
| `ActiveCount()` | 当前活跃替换数 |

### 设计要点

- 解释器或 JIT trampoline 在执行方法前调用 `Resolve`
- 如果替换生效，重定向到替换跳板
- `original_pointer` 支持安全回退，无需修改原始代码

## 与 MemoryDomain 的关联

- 每个热更新包在加载时创建一个独立的 MemoryDomain
- 域卸载时批量释放该包的所有堆分配（O(1)）
- 字符串表通过 `UnregisterDomain` 批量移除该域的字符串

## 与 codegen 的关系

- codegen 输出替换后的 IL 和元数据
- 热更新包通过 hot-update loader 映射到 runtime
- 方法替换表接收 codegen 产生的跳板函数
