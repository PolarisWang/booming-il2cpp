# 模式间切换指南

> AOT / JIT 两模式之间的切换操作指南。涵盖构建期配置、运行时检测、跨模式 dispatch 路由和平台约束。

---

## 构建期切换

两模式通过 `chaos-il2cpp convert-to-cpp` CLI 的 `--mode` 选项选择：

```bash
# AOT 模式（默认）
chaos-il2cpp convert-to-cpp --assembly GameLogic.dll --mode aot ...

# JIT 模式
chaos-il2cpp convert-to-cpp --assembly GameLogic.dll --mode jit ...
```

### 模式输出差异

| 维度 | AOT | JIT |
|------|-----|-----|
| C++ 函数体 | 完整编译 | AotCoreIr JSON + precode stub |
| 启动入口 | 直接执行 | `RegisterJitEntryMethods()` |
| HotpatchEntryV0::direct_ptr | AOT 函数地址 | JIT trampoline 地址 |
| 运行时入口表 | — | `.jit-entries` 段 |

### JitEntry 数据结构

JIT 模式生成 `.jit-entries` 段包含所有方法的序列化 IR：

```c
struct JitEntry {
    uint32_t token;               // ECMA method token
    uint32_t module_id;           // 模块 ID
    uint32_t json_len;            // AotCoreIr JSON 长度
    const char* json;              // AotCoreIr JSON (RegisterMethod 输入)
};
```

`RegisterJitEntryMethods` 运行时遍历此表为每个方法创建 `JitPrecode`，设置 trampoline。

## 运行时模式检测

### CHAOS_IL2CPP_JIT_MODE 预处理器

```cpp
// hotpatch_dispatch.h — CHAOS_IL2CPP_JIT_MODE 的 dispatch 路由
#if defined(CHAOS_IL2CPP_JIT_MODE)
    // JIT 模式：direct_ptr 指向 precode trampoline
    // 首次调用通过 trampoline → dispatch → Compile()
#else
    // AOT 模式：direct_ptr 直接指向 AOT 函数
    // 调用零开销
#endif
```

### 编译器宏检测

```cpp
namespace chaos::il2cpp::jit {
    // 这些函数在 AOT 模式下为空（由 #if 守卫）
    extern "C" void RegisterJitEntryMethods(const JitEntry*, uint32_t);
}
```

在纯 AOT 构建中，`jit_registration.h` 中的 `RegisterJitEntryMethods` 展开为空函数，不链接 JIT 子系统。

### 两模式 dispatch 路由总结

```
                      HotpatchEntryV0::direct_ptr
                               │
                     ┌─────────┴─────────┐
                     │                   │
                     ▼                   ▼
                  AOT函数         JIT trampoline
               (直接执行)             │
                                      ▼
                               JitStubEntry
                                      │
                                      ▼
                             JitStubDispatchImpl
                                      │
                              ┌───────┴───────┐
                              │               │
                              ▼               │
                         CAS Compile()        │
                              │               │
                              ▼               │
                         compiled.code        │
                              │               │
                              └──► direct_ptr │
                                              │
                                      compiled.code
```

## Hotpatch 与模式关系

| 场景 | AOT | JIT |
|------|-----|-----|
| patchdata 加载 | 同 | 同 |
| 方法替换 | direct_ptr = new_code | direct_ptr = new_code |
| 替换后冷调用 | 新代码立即生效 | 新代码立即生效 |
| 被内联方法 | 需重新 AOT 编译 | `InlineReverseMap` stale 标记触发 JIT 重编译 |
| Interpreter 回退 | 通过 dispatch slot | 通过 dispatch slot |

---

## 平台约束

| 特性 | AOT | JIT |
|------|-----|-----|
| Windows x64 | ✅ 完整支持 | ✅ 完整支持 |
| Linux x64 | ✅ 支持 | ✅ 支持 |
| ARM64 | ✅ 支持 | ❌ 不支持 |
| 移动端 (iOS/Android) | ✅ 支持 | ❌ 不支持 |

JIT 模式当前仅支持 x64 架构。ARM64 和移动端支持推迟到下一开发周期。
