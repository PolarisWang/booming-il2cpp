# 对象模型与相等性

## C++ 结构定义

托管对象在 C++ 侧表示为结构体，每个托管类型对应一个 C++ struct：
- 字段按顺序排列
- 对象头包含指向 `TypeInfo` 的指针（见下方类型身份系统）
- 值类型（struct）通过 `T` by value 传递
- 引用类型（class）通过指针传递

### 对象头 (A4-Dual+V2)

从 A4-Dual+V2 优化起，对象头按类型特征分为三种 variant：

```cpp
// PureType (8B): 无同步、无虚方法
struct PureTypeHeader {
    const TypeInfo* type_info = nullptr;
};

// ThinLockable (16B): 有同步、无虚方法
struct ThinLockableHeader {
    const TypeInfo* type_info   = nullptr;  // [0]
    uint64_t        sync_state  = 0;        // [8] — 薄锁/同步块索引
};

// Fat (24B): 有虚方法 + 同步
struct FatHeader {
    const TypeInfo* type_info   = nullptr;  // [0]
    const void**    vtable      = nullptr;  // [8]
    uint64_t        sync_state  = 0;        // [16] — 薄锁/同步块索引
};
```

三种 variant 的 `TypeInfo*` 均在偏移 [0]，因此类型信息可通过统一访问器 O(1) 获得：

```cpp
inline const TypeInfo* chaos_object_get_type_info(const void* obj) noexcept {
    return *static_cast<const TypeInfo* const*>(obj);
}
```

| Variant | 大小 | 同步能力 | 虚方法分派 | 典型类型 |
|---------|------|---------|-----------|---------|
| PureType | 8B | ❌ | ❌ | 值类型装箱、sealed 零虚方法 |
| ThinLockable | 16B | ✅ (薄锁) | ❌ | 多数引用类型 (String, Exception) |
| Fat | 24B | ✅ (薄锁) | ✅ (vtable) | 有虚方法的引用类型 |

Header kind 在编译时由 TypeInfo.flags[1:0] 确定，运行时通过 `ObjectNew` 按 kind 分配对应大小的头部。

### 同步状态机

```
                    CAS(expect=free, set=locked)
  空闲态 ─────────────────────────────────────→ 薄锁态
  sync_state=0                                   bits[1:0]=01
                                                  bits[63:2]=thread_id|recursion
    │                                               │
    │ 竞争发生                                       │ 竞争
    │ CAS 失败 → 膨胀                                │ CAS 失败 → 膨胀
    ↓                                               ↓
  膨胀态 ←───────────────────────────────────────────┘
  bits[1:0]=10
  bits[63:2]=SyncBlock*

  膨胀态时通过 SyncBlock->mutex 同步，
  TypeInfo* 在 Fat/ThinLockable 头部不变，
  无需从 SyncBlock 反查类型信息。
```

### 托管数组

```cpp
struct chaos_managed_array {

    const TypeInfo*      element_type_info = nullptr;

```

### 托管字符串

```cpp
struct chaos_managed_string {
    FatHeader header{};
    CHAOS_IL2CPP_INT32 length = 0;
};
```

注意：生成代码中的 struct 定义统一使用 `FatHeader` 作为成员类型（codegen 统一输出），运行时根据 TypeInfo.flags
确定实际头部大小进行分配。

## 类型身份系统 (Hybrid TypeInfo\*)

### TypeInfo 结构

```cpp
struct TypeInfo {
    const TypeInfo* parent;                  // 基类指针，System.Object = nullptr
    CHAOS_IL2CPP_UINT64 stable_id;           // FNV-1a 64-bit hash
    const InterfaceMapEntry* iface_map;      // AOT compile-time iface_map
    const InterfaceMapEntry* runtime_iface_map; // HotUpdate-追加的接口映射 (heap allocated)
    CHAOS_IL2CPP_UINT32 iface_count;         // AOT iface count
    CHAOS_IL2CPP_UINT32 runtime_iface_count; // HotUpdate 追加数
    CHAOS_IL2CPP_UINT8  type_shape;          // 1=reference, 2=value, 3=interface
    CHAOS_IL2CPP_UINT8  flags;               // bit[0:1]=header_kind, bit[2]=has_finalizer
    // 2 bytes padding
    const void**        vtable_array;        // 统一 vtable 访问指针 (V2 自指 &inline_slots[0])
    CHAOS_IL2CPP_UINT32 vtable_length;       // vtable slot 数
    // 4 bytes padding
};
// sizeof = 64 bytes
```

### TypeInfoV2 (内联 vtable)

```cpp
struct TypeInfoV2 {
    TypeInfo                base;            // 64B (vtable_array = &inline_slots[0])
    const void*             inline_slots[6]; // 48B: 内联 vtable 槽
};
// sizeof = 112 bytes
```

### 身份比较规则

类型身份通过 **指针比较** 判断，而非整数 switch：

| 类别 | TypeInfo 来源 | 保证 |
|------|---------------|------|
| AOT 静态类型 | `inline constexpr`（C++17 保证跨 TU 唯一地址） | 编译期固定 |
| HotUpdate 动态类型 | `chaos_register_type()` heap 分配 | 运行时注册一次，指针唯一 |

```cpp
// O(1) 指针比较
bool chaos_is_type_compatible(const TypeInfo* actual, const TypeInfo* target) {
    auto* current = actual;
    while (current != nullptr) {
        if (current == target) return true;  // 指针相等
        current = current->parent;           // 走 parent 链
    }
    return false;
}
```

### FNV-1a stable_id

- 64-bit FNV-1a hash of managed type subjectId
- C# 端 `ComputeStableTypeId()` 与 C++ 端 `chaos_compute_type_stable_id()` 算法一致
- 用于 `switch (type_info->stable_id)` 场景（接口实现检测）

### 兼容性整数别名

每个 TypeInfo 实例附带一个 `static_cast<CHAOS_IL2CPP_INTPTR>(stableId)` 别名，用于 `switch case` 标签：

```cpp
inline constexpr TypeInfo chaos_type_info_X = { nullptr, 0x3789ULL, 1 };
inline constexpr CHAOS_IL2CPP_INTPTR chaos_type_id_X = static_cast<CHAOS_IL2CPP_INTPTR>(0x3789ULL);
```

### 动态类型注册 (HotUpdate)

```cpp
TypeInfo* chaos_register_type(const char* name, const TypeInfo* parent,
                              CHAOS_IL2CPP_UINT8 type_shape,
                              CHAOS_IL2CPP_UINT64* out_stable_id);
const TypeInfo* chaos_find_type_by_stable_id(CHAOS_IL2CPP_UINT64 stable_id);
```

- 最大 256 个动态类型
- 写操作 mutex 同步，读操作 lock-free
- parent 可指向静态 TypeInfo（AOT 类型当作动态类型的基类）

## 类型身份辅助函数

- `IsValueType` — 检测是否为值类型
- `IsReferenceType` — 检测是否为引用类型
- `IsPrimitive` — 检测是否为基本类型
- `HasFinalizer` — 检测是否有终结器
- `IsArray` — 检测是否为数组类型
- `IsEnum` — 检测是否为枚举类型

## 相等性 7 级优先级

| 优先级 | 规则 | 说明 |
|--------|------|------|
| 1 | ReferenceEquals | 同一引用返回 true |
| 2 | Null check | 任意一方为 null 返回 false |
| 3 | Type identity | 类型不同返回 false |
| 4 | Value type: field-by-field | 值类型逐字段比较 |
| 5 | String: `op_Equality` | 字符串走专用路径 |
| 6 | Delegate: target/method | 委托比较目标和 method pointer |
| 7 | Default: `Equals` override | 退化为调用托管 Equals |
