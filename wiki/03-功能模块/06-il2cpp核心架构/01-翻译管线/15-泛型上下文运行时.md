# 泛型上下文运行时

## 核心职责

跟踪封闭泛型类型和方法的实例化。运行时回答"这个泛型实例的类型参数是什么"——这是反射、相等性检查和特化派发的核心。

## 关键函数

| 函数 | 说明 |
|------|------|
| `RegisterGenericInstantiation(open_token, type_args...)` | 开放泛型 token + 类型参数 → 封闭 token |
| `RegisterMethodGenericContext(method_token, class_type_args, method_type_args)` | 关联类型参数和方法参数 |
| `GetGenericContextForMethod(method_token)` | 查询方法的泛型上下文 |
| `GetClassTypeArg(context, index)` | 查询类类型参数 |
| `GetMethodTypeArg(context, index)` | 查询方法类型参数 |

## 与 codegen 的关系

- 对 AOT 编译中遇到的每个封闭泛型类型实例化（如 `List<int>`），codegen 发射 `RegisterGenericInstantiation` 调用
- 对泛型方法实例化，发射 `RegisterMethodGenericContext`
- 运行时调用 `typeof(T)` 或 `MakeGenericMethod` 时通过这些注册表解析类型参数，无需重新解析元数据

## 位置

- 模块: `chaos_runtime_core`
