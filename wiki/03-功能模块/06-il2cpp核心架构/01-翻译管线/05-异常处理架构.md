# 异常处理架构

## 5 种 EH Shape

| Shape | 描述 | C++ 模式 |
|-------|------|---------|
| CatchOnly | 只有 catch 子句 | `try { ... } catch (T&) { ... }` |
| FilterOnly | 只有 filter 子句 | `try { ... } catch (...) { if (filter) { ... } }` |
| FinallyOnly | 只有 finally 子句 | `try { ... } catch (...) { cleanup; throw; }` |
| CatchAndFinally | catch + finally 混合 | `try { ... } catch (T&) { ... } }` + finally 展开 |
| FilterAndFinally | filter + finally 混合 | `try { ... } catch (...) { filter; cleanup; }` |

## 异常处理的关键约束

- Filter 子句通过 `catch (...) { if (filter_expr) { ... } else { throw; } }` 模拟
- Finally 通过 `catch (...) { finally_code; throw; }` + normal exit 路径实现
- 不允许在 filter 中执行托管内存分配
- 异常对象通过 `raise_managed_exception` 桥接函数抛出
- C++ 异常与托管异常在边界处转换

## Runtime Support

异常处理需要的 runtime helper：
- `raise_managed_exception` — 抛托管异常
- 异常元数据查询（类型、消息、stack trace）
