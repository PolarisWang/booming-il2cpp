# 输入合约模型

## AotCoreIrArtifact 结构树

Loader 层输出的统一输入合约，是整个管线的数据起点：

```
AotCoreIrArtifact
 ├── AssemblyName                  -- 程序集名称
 ├── TypeLookup                    -- 类型查找表（TypeDefinitionIndex → TypeDefinition）
 ├── MethodLookup                  -- 方法查找表
 ├── FieldLookup                   -- 字段查找表
 ├── StringLookup                  -- 字符串字面量表
 ├── GenericInstantiations         -- 泛型实例化集合
 └── ForwardedTypes                -- 类型转发信息
```

## AotCoreIrMethodArtifact

每个方法的编译输入：

```
AotCoreIrMethodArtifact
 ├── MethodDefinition              -- 方法元数据（参数、返回值、泛型参数）
 ├── ILBody                        -- raw IL 字节流
 ├── EHTable                       -- 异常处理子句表
 ├── LocalVariableInfo             -- 局部变量签名
 ├── GenericContext                -- 泛型上下文（如有）
 └── ReferencedTokens              -- 方法内引用的 token 列表
```

## AotCoreIrInstructionArtifact

单条 IL 指令的编译输入：

```
AotCoreIrInstructionArtifact
 ├── Opcode                        -- IL opcode
 ├── Operand                       -- 指令操作数（token/br_target/primitive）
 ├── EvalStackBefore               -- 执行前求值栈状态（类型快照）
 └── EvalStackAfter                -- 执行后求值栈状态
```

## 引用与类型信息

- `TypeReferenceInfo`：类型引用的 resolved/unresolved 状态，含 assembly 来源
- `MethodReferenceInfo`：方法引用的 resolved 状态，含 declaring type、参数列表
- `FieldReferenceInfo`：字段引用的 resolved 状态，含 declaring type、字段类型
