# 已消除的禁止模式

以下性能反模式已被修复，新代码不得重新引入。

## 翻译层反模式

| 反模式 | 问题 | 替代方案 |
|--------|------|---------|
| Emitter 扫 IL 猜 shape | 违反五层职责，Emitter 不应反推语义 | CodeGen 层通过 LoweringPlan 传递 shape |
| Linker 做 lowering 决策 | 职责混淆，Linker 不应选 lowering family | CodeGen 层选择 lowering family |
| Loader 做语义归一化 | Loader 只负责读取，不做语义转换 | SemanticWorld 层归一化 |

## 性能反模式

| 反模式 | 问题 | 替代方案 |
|--------|------|---------|
| 运行时扫描所有字符串 | 每次调用 O(n) 扫描 | StringId 预计算 hash |
| 线性搜索泛型实例化 | 大量泛型时性能退化 | 编译期展开 + 直接函数指针 |
| 重复计算 cctor flag | 每次访问静态字段检查 flag | `std::call_once` 一次初始化 |
| 字符串拼接用临时对象 | 中间分配过多 | pair concat 折叠优化 |
| Emitter 侧反射扫描 | 运行时按名称查找类型 | AOT baked lookup table |
| 未缓存 token 解析 | 每次调用重解析 token | 编译期解析 token 为直接指针 |

## 编码反模式

| 反模式 | 问题 | 替代方案 |
|--------|------|---------|
| 宏定义中隐藏控制流 | 调试困难、违反直觉 | 内联函数 |
| 手动位运算管理 StringId | bit 63 标记易出错 | `chaos_is_string_id()` 等辅助函数 |
| 直接使用原生类型 | 跨平台不一致 | `CHAOS_IL2CPP_*` 宏抽象层 |
