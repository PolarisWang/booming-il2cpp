# 结构化控制流恢复翻译表

## 概述

NativeAOT 代码生成器不再对每条 IL 指令发射 `chaos_ip_N:` 标签 + `goto chaos_ip_{N+1}`。改为通过 CFG 分析恢复结构化控制流（if-else、switch、while/do-while），消除直落 goto chain。

## 流程图

```
指令列表 → BuildBasicBlocks() → 基本块列表
                               ↓
                         BuildControlFlowGraph() → CFG
                               ↓
                          IsCfgReducible() ──false──→ EmitInstructionRange() [回退 goto 风格]
                               ↓ true
                     FindLoopHeaders() [Dominator 分析]
                               ↓
                         RecoverStructure() → 结构化节点树
                         (if-else/switch/while/do-while)
                               ↓
                         EmitStructuredNode() → C++ if/else/switch/while/do-while
```

## 关键文件

| 文件 | 职责 |
|------|------|
| `Emission/NativeAotLoweringPlanner.StructuredControlFlow.cs` | CFG 构建 + 结构化恢复算法 + 自然循环检测 + Dominator 分析 |
| `Emission/NativeAotLoweringPlanner.MethodEmission.cs` | 结构化发射方法族（含 while/do-while/break/continue 发射） |
| `Emission/NativeAotLoweringPlanner.ExceptionEmission.cs` | 异常 handler 的结构化发射 |

## 数据结构

| 类型 | 说明 |
|------|------|
| `BasicBlock` | 基本块：起始偏移、体指令列表、终结指令、分支目标 |
| `ControlFlowGraph` | CFG：块列表、偏移→块索引映射、可归约性标志 |
| `BasicBlockNode` | 叶子节点：单一基本块 |
| `SequenceNode` | 顺序节点：子节点序列 |
| `IfThenElseNode` | 条件节点：条件块 + then/else 分支 + merge 点 |
| `SwitchNode` | 开关节点：开关块 + case body + default + merge 点 |
| `LoopNode` | 循环节点：header block + body + exit offset + while/do-while 标记 + latch block |
| `NaturalLoopInfo` | 自然循环信息：header 索引、body 块索引集合、latch 索引集合 |

## 结构化覆盖范围

| 模式 | 检测 | 发射 |
|------|------|------|
| 直落块序列 | `IsBlockTerminatorOpcode` 为 false → fall-through | 块内容顺序发射，无 label/goto |
| 无条件分支 | `br` / `leave` | `goto chaos_ip_target` |
| 条件分支 | `brtrue` / `brfalse` / `beq` / `bne.un` / `bge`(`.un`) / `bgt` / `ble` / `blt` | `if (condition) { ... } else { ... }` |
| 开关 | `switch` | `switch (value) { case N: ... break; }` |
| while 循环 | natural loop: header 有 conditional branch | `while (cond) { body }` |
| do-while 循环 | natural loop: header 无 conditional, latch 有回边 | `do { body } while (cond);` |
| break | `br target == exitOffset` (在循环体内) | `break;` |
| continue | `br target == headerOffset` (在循环体内) | `continue;` |
| 终结指令 | `ret` / `throw` / `rethrow` / `endfilter` / `endfinally` | 直接发射，无后继 goto |

## 未覆盖模式（回退）

| 模式 | 原因 | 行为 |
|------|------|------|
| 交叉分支（不规则 CFG） | 无法表示为结构化 if-else/switch/while/do-while | `IsCfgReducible = false` → 回退 goto 风格 |
| 不可归约循环（多 header 共享 body 等） | Dominator 分析无法识别自然循环 | 同上 |

## merge 点识别

`FindMergePoint()` 对 then/else 两条路径分别做 `WalkForward()`，取可达块集合的交集中索引最小的块作为 merge 点。

## `_suppressGotoNext` 机制

`EmitStructuredInstructionRange()` 入口处设置 `_suppressGotoNext = true`，使 `AppendGotoNext()` 在结构化上下文中变为空操作（no-op）。退出时在 `finally` 块中恢复为 `false`，确保 fallback 路径的 `EmitInstructionRange()` 正确发射 goto。

## `LoopContextStack` 机制

`Stack<(int headerOffset, int exitOffset)>` — 嵌套循环上下文栈。`EmitStructuredLoop()` 入口处 push `(headerOffset, exitOffset)`，退出时在 `finally` 块中 pop。`EmitBasicBlockContent()` 发射 `br`/`leave` 前检查栈顶：

- target == `exitOffset` → 发射 `break;`
- target == `headerOffset` → 发射 `continue;`
- 其他情况 → 正常发射 `goto chaos_ip_target;`

栈结构保证内层循环的 break/continue 不影响外层。

## 与异常处理集成

5 种异常 shape（catch-only / filter-only / finally-only / catch-and-finally / filter-and-finally）中的每个 partition（prefix / try / handler / tail）各自独立调用 `EmitStructuredInstructionRange()`。统一替换前导的 `goto chaos_ip_firstInstr` + `EmitInstructionRange` → `EmitStructuredInstructionRange`。
