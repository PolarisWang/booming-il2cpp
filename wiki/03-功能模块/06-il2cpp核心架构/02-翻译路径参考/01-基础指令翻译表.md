# 基础指令翻译表

## 常量加载

| Opcode | 翻译策略 | 输出类型 |
|--------|---------|---------|
| `ldnull` | `nullptr` | ManagedPointer |
| `ldc.i4.*` | 整数常量直接嵌入 | Int32 |
| `ldc.i8` | 64 位整数常量 | Int64 |
| `ldc.r4` / `ldc.r8` | 浮点常量 | Float / Double |
| `ldstr` | `new System.String{}` 堆分配 + raw 指针入栈 | ManagedPointer(String) |

## 参数/局部变量

| Opcode | 翻译策略 |
|--------|---------|
| `ldarg.0` / `ldarg.*` | 从函数参数列表直接读取 |
| `starg` | 写回参数槽 |
| `ldloc.*` | 从局部变量表读取 |
| `stloc.*` | 写入局部变量表 |
| `ldloca` | 取局部变量地址（托管指针） |
| `ldarga` | 取参数地址（托管指针） |

## 类型转换

| Opcode | 翻译策略 |
|--------|---------|
| `conv.i1` / `conv.i2` / `conv.i4` / `conv.i8` | 原生有符号整数转换（static_cast） |
| `conv.u1` / `conv.u2` / `conv.u8` | 原生无符号整数转换 |
| `conv.r4` / `conv.r8` | 浮点转换 |
| `conv.ovf.*` | 带溢出检查的转换（`conv.ovf.i1` / `conv.ovf.u1` 已实现） |
| `conv.u` / `conv.i` | IntPtr 相关转换 |

## 算术与位运算

| 类别 | Opcode 集合 | 翻译策略 |
|------|-----------|---------|
| 算术 | `add` / `sub` / `mul` / `div` / `rem` / `neg` | 原生算术运算符 |
| 位运算 | `and` / `or` / `xor` / `not` | 原生位运算符 |
| 移位 | `shl` / `shr` / `shr.un` | 原生移位运算符 |
| 溢出检查 | `add.ovf.*` / `sub.ovf.*` / `mul.ovf.*` | 带溢出检测的算术运算 |

## 比较

| Opcode | 翻译策略 |
|--------|---------|
| `ceq` / `cgt` / `clt` | 原生比较运算符 |
| `cgt.un` / `clt.un` | 无符号比较 |

## 分支

| 类型 | Opcode 集合 | 翻译策略 |
|------|-----------|---------|
| 无条件 | `br` | `goto` 或 if/else 结构 |
| 条件 | `brtrue` / `brfalse` | 值判零跳转 |
| 比较分支 | `beq` / `bne.un` / `bge` / `bgt` / `ble` / `blt` / `bge.un` | 比较后条件跳转 |
| 跳转表 | `switch` | 跳转表派发 |
| 离开保护块 | `leave` | 离开 try/catch/finally 块 |

## 栈操作

| Opcode | 翻译策略 |
|--------|---------|
| `dup` | 复制栈顶值到局部变量 |
| `pop` | 丢弃栈顶值 |

## 内存与局部分配

| Opcode | 翻译策略 |
|--------|---------|
| `cpblk` | 内存块拷贝（EmitCopyBlock） |
| `localloc` | 局部栈分配（EmitLocalAlloc） |
