# 数组与类型检查翻译表

## 数组操作

| Opcode | 翻译策略 |
|--------|---------|
| `newarr` | `array_new(element_type, length)` — 分配托管数组 |
| `ldlen` | 读取数组 length 字段 |
| `ldelem.*` | 按元素类型读取数组元素（带边界检查） |
| `stelem.*` | 按元素类型写入数组元素（带边界检查） |
| `ldelema` | 取数组元素地址（托管指针） |
| `newarr<T>` | 泛型数组分配 |

## 类型检查与转换

| Opcode | 翻译策略 |
|--------|---------|
| `castclass` | 类型兼容性检查 + 强转，失败抛 `InvalidCastException` |
| `isinst` | 类型兼容性检查，返回 `null` 或原引用 |
| `box` | `box_value(val, type)` — 值类型→Object |
| `unbox` | `unbox_value(obj, type)` — Object→值类型指针 |
| `unbox.any` | unbox + 值拷贝 |

## 对象操作

| Opcode | 翻译策略 |
|--------|---------|
| `ldobj` | 从托管地址加载值类型 |
| `stobj` | 存储值类型到托管地址 |
| `cpobj` | 值类型拷贝 |
| `initobj` | 值类型零初始化 |

## 间接操作

| Opcode | 翻译策略 |
|--------|---------|
| `ldind.*` | 从指针间接加载值 |
| `stind.*` | 间接存储值到指针 |
| `sizeof` | 编译期计算类型大小 |
