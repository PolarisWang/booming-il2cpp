# 静态初始化与对象相等性翻译表

## 静态初始化 (cctor) 降级

| 场景 | 降级策略 | 说明 |
|------|---------|------|
| 无 static constructor | 无代码生成 | 零开销 |
| Simple static field = constant | 编译期常量折叠 | 无运行时开销 |
| Static field = new object | `std::call_once` 惰性初始化 | 线程安全惰性初始化 |
| Complex cctor | `std::call_once` + 完整 cctor body | 带循环依赖检测 |
| Circular cctor dependency | 运行时回退 | 检测到循环时回退到安全默认值 |

## 对象相等性

### String Equality

`String.op_Equality` / `String.Equals` 专用路径：

| 场景 | 翻译策略 |
|------|---------|
| StringId vs StringId | hash 比较（快速路径） |
| StringId vs string object | 物化后完整比较 |
| string vs string | `memcmp` / 逐字符比较 |
| null check 前置 | 任意一方为 null 则短路 |

### Object.Equals 优先级

| 优先级 | 规则 | 实现 |
|--------|------|------|
| 1 | ReferenceEquals | 指针比较 |
| 2 | Null check | `obj == nullptr` 检查 |
| 3 | Type identity | runtime type 指针比较 |
| 4 | Value type field-by-field | 逐字段 memcmp |
| 5 | String op_Equality | StringId hash 比较 |
| 6 | Delegate equality | target + method 指针比较 |
| 7 | Default Equals override | 调用托管 `Equals` 虚方法 |
