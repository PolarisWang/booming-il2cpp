# 代码级禁止模式

以下模式在 C# 代码生成中禁止使用，列为必须修复的违规。

## 禁止模式总表

| 模式 | 风险 | 必须替代为 |
|------|------|---------|
| Emitter 中扫描 IL 判断 shape | 违反五层职责边界 | 通过 LoweringPlan 传递 |
| Linker 中做 lowering family 选择 | 职责外溢 | 推迟到 CodeGen |
| 手动位运算管理 StringId tag | 易遗漏/错误 | `chaos_is_string_id()` 辅助函数 |
| 直接调用函数指针绕过桥接 | 绕过运行时托管边界 | 使用 `resolve_virtual_method` 等 |
| 编辑期硬编码虚表偏移 | 运行时类型变化导致崩溃 | 通过桥接函数解析 |
| 手动计算 array/object 大小 | GC 信息不一致 | `object_new` / `array_new` |
| 在 filter block 中分配托管内存 | CLR 违禁 | 分配移到 filter 外部 |
| 裸 `int32_t` 等原生类型 | 不能适配多平台 | `CHAOS_IL2CPP_INT32` 等宏 |
| 编译期假设指针大小 | 64/32 位不兼容 | 使用 `intptr_t` / `uintptr_t` |
| 跨模块直接引用符号 | 破坏依赖方向 | 通过合约桥接函数 |
| 手动内存复制代替装箱 | 跳过 GC 跟踪 | `box_value` / `unbox_value` |
| 直接读写托管对象内存 | GC 移动对象后失效 | `field_get_value` / `field_set_value` |

## 违反处理

- 以上禁止模式在代码审查中自动标记
- 违反导致构建失败（由 `check_arch.py` 和相关检查强制执行）
