# 合约边界与桥接函数

## 合约文件总览

| 边界 | 合约文件 | 说明 |
|------|---------|------|
| 代码生成↔运行时 | `contracts/native/v0/codegen_bridge.h` | CodegenBridgeV0：注册、元数据解析、装箱、虚分发、委托、StringId 标记 |
| 运行时 ABI | `contracts/native/v0/runtime_abi.h` | RuntimeAbiV0：生命周期、分配、GC handle、异常、反射查询、能力描述符 |
| 引擎合约 | `contracts/engine/v0/` | lifecycle.h, callback.h, ownership.h, thread-model.md |
| 产物 schema | `contracts/artifacts/v0/schemas/` | 11 个 JSON schema |
| 共享 ABI | `contracts/shared/v0/` | delegate-abi, exception-boundary, handle-model, identity-model, object-model |

## codegen_bridge.h

`CodegenBridgeV0` 定义的核心桥接函数：

| 函数 | 用途 |
|------|------|
| `register_codegen` / `bootstrap_runtime` | 代码生成注册 |
| `resolve_type_by_token` / `query_type_capability` | 类型元数据解析 |
| `resolve_method_by_token` / `resolve_field_by_token` | 方法/字段元数据解析 |
| `box_value` / `unbox_value` | 装箱操作 |
| `resolve_virtual_method` / `invoke_virtual` / `resolve_virtual_method_by_token` | 虚方法分发 |
| `create_delegate` / `delegate_invoke` | 委托创建与调用 |
| `resolve_icall` | 内部调用解析 |

状态码：`CHAOS_BRIDGE_STATUS_OK`(0) 至 `CHAOS_BRIDGE_STATUS_RUNTIME_CALL_FAILED`(16)。

StringId 标记系统：
- `CHAOS_STRING_ID_TAG` 定义为 bit 63
- `chaos_is_string_id()` — 检测是否有 bit 63 标记
- `chaos_extract_string_id()` — 提取 StringId 值
- `chaos_make_string_id_value()` — 创建 StringId 标记值

## runtime_abi.h

`RuntimeAbiV0` 定义的运行时 ABI：

| 函数 | 用途 |
|------|------|
| `runtime_init` / `runtime_shutdown` | 运行时生命周期 |
| `thread_attach` / `thread_detach` | 线程生命周期 |
| `object_new` / `array_new` / `string_new_utf8` | 对象分配 |
| `gc_handle_new` / `gc_handle_free` | GC handle 管理 |
| `raise_managed_exception` | 异常抛出 |
| `field_get_value` / `field_set_value` | 字段操作 |
| `assembly_get_image` / `image_find_type` | 程序集/类型反射查询 |
| `type_find_method` / `type_find_field` | 方法/字段反射查询 |
| `type_get_generic_type_definition` / `generic_context_get_*` | 泛型上下文查询 |
| `RuntimeTypeCapabilityInfoV0` | 类型能力描述（值大小、向量宽度等） |
