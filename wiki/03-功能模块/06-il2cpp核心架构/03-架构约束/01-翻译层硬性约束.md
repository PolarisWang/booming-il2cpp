# 翻译层硬性约束

## cctor 约束

- 不允许在 cctor 中分配托管对象（可能触发嵌套 cctor 死锁）
- cctor 必须线程安全（`std::call_once`）
- 循环依赖 cctor 必须有运行时回退机制

## 虚方法约束

- 虚方法调用必须通过 `resolve_virtual_method` 桥接函数
- 不允许在编译期硬编码虚表偏移
- 虚方法委托必须通过 `ldvirtftn` 获取函数指针

## 字符串 ID 约束

- 所有编译期已知字符串必须编码为 StringId（bit 63 标记）
- **`ldstr` 指令必须 push tagged StringId，不允许 per-call 堆分配**
- StringId 不能泄漏到托管代码侧（在 boundary 场景需物化为 `System.String`）
- 所有接收 `string` 参数的外部 runtime helper 必须同时处理 StringId（快速路径）和物化 String 对象指针（fallback）
- 字符串比较必须优先走 hash 比较快速路径（StringId 比较 O(1)）

## 跨 DLL 类型身份约束

- TypeInfo 指针相等（`== &chaos_type_info_XXX`）仅在同一 DLL 内保证
- 跨 DLL 场景必须 fallback 到 `stable_id` 相等比较
- Codegen 生成的 type comparison 必须生成双条件：`pointer_equal || stable_id_equal`
- 单 DLL 场景走指针快速路径（1 条指令），跨 DLL 自动走 stable_id

## 跨 DLL 方法分派约束

- 跨 DLL 方法调用必须通过 `method_table` 间接分派，不允许 IAT 或 inline
- `method_table` 位于 runtime_core DLL 的 `.data` 段，对所有 AOT DLL 可见
- 热更 DLL 通过 `WriteMethodTable()` API 替换方法条目
- 每个 `method_table` 条目附带 `generation` 版本戳，用于检测热更卸载后的悬空指针

## 委托约束

- 委托创建必须通过 `create_delegate` 桥接函数
- 委托调用必须通过 `delegate_invoke`
- 不允许直接调用委托的函数指针

## 异常约束

- Filter 子句中不允许托管内存分配
- 必须通过 `raise_managed_exception` 抛托管异常
- C++ 异常必须在托管边界处正确转换

## 浮点约束

- 浮点运算直接使用原生 `float`/`double` 运算
- 浮点 bitcast 通过 `memcpy` 或 `bit_cast` 实现（避免 UB）

## 对象约束

- 托管对象在 C++ 侧必须通过指针访问
- 值类型通过 `T` by value 传递
- GC 对象必须通过 GC handle 管理

## 反射约束

- 反射查询必须通过 `runtime_abi.h` 的反射函数
- 不允许在编译期硬编码反射结果
- 泛型反射需要运行时上下文

## ABI 约束

- 所有桥接函数必须遵循 `codegen_bridge.h` 定义的 ABI
- 返回值 carrier kind 必须匹配调用方期望
- 不允许在桥接函数中修改求值栈结构

## 泛型约束

- 不允许在运行时动态实例化开放泛型
- 每个封闭泛型实例化独立生成 C++ 代码
- 泛型上下文通过 GenericContext 参数传递

## 数组约束

- 数组边界检查必须在所有 `ldelem`/`stelem` 中生成
- 数组长度通过对象头读取

## 求值栈约束

- 求值栈操作在编译期完全解析（不生成运行时栈模拟代码）
- 每指令的栈深度变化在 lowering 前已知
