# 实现层优化决策

**来源**: 代码优化审计结果，涵盖缓存、索引、消除线性扫描等。参见 `02-翻译路径参考/07-已消除的禁止模式.md`。

## 决策

### 缓存决策

| # | 决策 | 说明 |
|---|------|------|
| 1 | Token 解析结果缓存 | 编译期解析 metadata token 后缓存结果指针 |
| 2 | 类型查找缓存 | TypeLookup 缓存 resolved type 结果 |
| 3 | StringId hash 预计算 | 编译期预计算所有字符串 hash |
| 4 | AOT baked lookup table | 运行时用预生成表替代按需反射 |

### 索引决策

| # | 决策 | 说明 |
|---|------|------|
| 1 | 方法查找索引 | TypeDefinition → MethodList 按 token 索引 |
| 2 | 字段查找索引 | TypeDefinition → FieldList 按 token 索引 |
| 3 | 泛型实例化索引 | GenericInstantiation → 具体代码的映射表 |
| 4 | 委托创建索引 | delegate type → create_delegate 的特化路径 |

### 消除 O(n) 扫描

| # | 优化项 | 替代方案 |
|---|--------|---------|
| 1 | 线性搜索静态字段 | 全局静态变量直接寻址 |
| 2 | 线性搜索类型 | TypeLookup 哈希表索引 |
| 3 | 线性搜索方法 | MethodLookup 哈希表索引 |
| 4 | 运行时反射按名称查找 | AOT baked table 直接索引 |
| 5 | 字符串逐个比较 | StringId hash 比较快速路径 |
| 6 | 泛型实例化匹配 | 特化展开为独立函数 |

### 编码层优化

| # | 决策 | 说明 |
|---|------|------|
| 1 | `CHAOS_IL2CPP_` 宏抽象 | 所有原生类型和 STL 类型通过宏定义，消除平台差异 |
| 2 | 辅助函数封装 | bit 63 标记操作封装为 `chaos_is_string_id()` 等函数 |
| 3 | 编译期断言 | 在编译期验证 CarrierKind 映射、StringId 布局等不变量 |
| 4 | 模板特化替代运行时分支 | 编译期展开的泛型通过 C++ 模板特化实现 |

## 关键约束

- 所有优化必须在保证语义正确的前提下进行
- Phase A 期间不做侵入性优化（如全局寄存器分配）
- 优化带来复杂度增加的，必须有性能 benchmark 数据支持
