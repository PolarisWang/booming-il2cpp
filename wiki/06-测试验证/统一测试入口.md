# 统一测试入口

> 代码库唯一测试总入口。一条命令跑完全部层，做方案 C 整合时统一。
> 关联：[`测试分层.md`](./测试分层.md)、[`新增测试接入规范.md`](./新增测试接入规范.md)

## 入口

- 开发者统一入口：`python tests/runner/test_driver.py`
- CI 预设入口：`python scripts/ci_test.py --preset <name>`
- 统一报告：`tests/runner/test-report.json`（可选 `--junit out.xml`）

```bash
# 全部三层
python tests/runner/test_driver.py --layer all --quick

# 只跑单元层（快）
python tests/runner/test_driver.py --layer unit

# 只跑单组
python tests/runner/test_driver.py --layer unit --group snapshot
python tests/runner/test_driver.py --layer unit --group codegen
python tests/runner/test_driver.py --layer unit --group driver

# CI preset
python scripts/ci_test.py --preset managed-codegen
python scripts/ci_test.py --preset managed-full
python scripts/ci_test.py --preset native-contracts
python scripts/ci_test.py --preset foundation-smoke
```

## 层与 adapter

| 层 | adapter | 内容 | 位置 |
|----|---------|------|------|
| unit | dotnet | CodeGen.Tests / Driver.Tests / SnapshotTests | `tests/managed/`, `tests/snapshots/` |
| integration | native | CTest（abi/bridge/common/engine-binding/gc/hot-update/interpreter/runtime-core） | `tests/contracts/native/**` |
| e2e | python | foundation-dll chunk 验证 + ci_smoke | `testing/foundation-dll/verification/` |

契约：`tests/suite_contract.yaml`（单一事实源：定义层、adapter、group。加测试=加 group 条目，不改 driver）。

## 关键参数

- `--layer {unit,integration,e2e,all}` 选层
- `--group NAME` 缩窄到单个组
- `--quick` 用 `--no-build`（假设已构建；本地改过源码先正常 build 一次）
- `--timeout N` 每步超时秒
- `--json FILE` / `--junit FILE` 报告输出

## no-skip 规则（强制）

**没有 "skip" 状态。** 每个测试要么 PASS 要么 FAIL。当前失败若有已知原因，登记在
`tests/runner/baselines/known-failures.{layer}.yaml`。driver **照样运行并报告为 FAIL**，
标注 `[KNOWN-FAIL]`；若一个组的所有失败都是 known，运行门返回 0（绿），但失败在报告中完整可见。
修复后删除对应 baseline 条目，则寄存器门会在它回归时失败。

当前已知失败（unit）：CodeGen.Tests `AotCoreIrLoweringTests`（~28 个）+ 两个 order 依赖 flaky
（fixture 70 methods.json、`CreatePseudoMetadataHandle_ReturnsNonZero`）。

## 完成前置

完成改动后，用 `python tests/runner/test_driver.py --layer unit` 自测：
非 `known` 的 `[FAIL]` 出现即真实回归（`OVERALL: FAILED`），需修复后再推。

## 注意

- `--quick` 依赖最新构建产物；native-contracts 需 `build/native` 已由 cmake 配置过。
- `testing/src/managed/Chaos.IL2CPP.Tests.MetadataWriter` 缺测试 SDK 包（基础设施缺口），当前不跑、不 skip。
