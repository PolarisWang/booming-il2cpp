## 一、起点：A2 根因定案

- A2 交接档误判"解释器 UIntPtr 编组"。实证(SEH 捕获)定案：**`Vector<int>` 方法是 codegen 对 SIMD reducer 操作数未物化** → 传 8B 槽地址当 32B Vector256 指针 → 越界读栈 → 条件性 AV(0xC0000005)。
- 修复：`EmitExternalRuntimeTableDispatch` + `EmitVectorOperandMaterialization` 物化 32B carrier（commit `46a417b23`）。
- 文档：`assessments/hotupdate-interpreter-dispatch-a2-resubmit-2026-08-13.md`

## 二、解释器能力评审（峰平谷 + 深挖）

- 定位：chaos 解释器是"独立自足现代分层解释 VM"——5级执行管线+computed-goto+111-opcode IR+完整SEH+到JIT的tier/OSR/deopt+热更深度集成+精确GC帧扫描写屏障（峰）。
- 谷#1 最深：**对象模型自研沙箱、非GC、与真实GC对象两套不互通**，且裸指针跨界 + 非GC存储被反向注册GC root = 真实内存安全风险。
- 文档：`assessments/interpreter-capability-peak-plateau-valley-2026-08-13.md` + `interpreter-deepdive-2026-08-13.md`
