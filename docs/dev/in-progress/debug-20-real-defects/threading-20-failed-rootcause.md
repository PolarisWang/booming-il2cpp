## 二、根因：Interlocked 的 Int32/UInt32/UInt64 重载**从未注册 shape**

> ⚠️ **本节早先版本判断有误，已更正。** 原写「注册用 `&`、subject id 无 `&`，写法不一致」——
> **错误**。真实 IR callee **是带 `&` 的**，`&` 参与匹配且写法正确。
> 我之前读的是 `subjects.metadata.json`（ATG 侧另一套写法），不是 AOT Core IR。

### 2.1 真实 callee（AOT Core IR）

`aot-core-ir.json` 中 `instruction.Callee` 的实际形态：


## 二·补、泛型重载是独立的第二根因

`CompareExchange_7_int_int_int_3` 失败，但**非泛型** `CompareExchange_7_int_int_int_0` 的
外部符号 `..._CompareExchange_System_Int32_..._`（`:9143`）**确实转发**到
`ChaosInterlockedCompareExchangeInt32`。

失败的 `_3` 是**泛型实例化**形态：
`..._CompareExchange_System_Int32__System_Int32_System_Int32__System_Int32_System_Int32_()`（`:9148`）
—— 又落 catch-all。

**即：非泛型已通，泛型 `CompareExchange<T>` 实例化未通**（属 `git-instantiation` 线）。
