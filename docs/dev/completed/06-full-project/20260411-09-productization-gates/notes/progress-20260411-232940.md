- 为 `subjects/MobileHelloWorldProof/subject.manifest.json` 新增显式 `windows-android-soak` 矩阵，使用 `android-runtime-observe` pipeline，但把长时运行参数固定到矩阵 `executionContext.runtimeArguments`，从而避免污染普通 `windows-android-runtime` smoke 路径。

- 为 `build/toolchains/run/testing/subject_workers.py` 增加 Android runtime 参数桥接：
