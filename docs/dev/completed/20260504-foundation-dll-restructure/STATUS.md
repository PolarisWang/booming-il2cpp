# Foundation-dll 项目结构重构

## Phase: roadmap

## 设计摘要

### 边界拍板

- 每个 family 的源码统一在一个 family 目录下，按角色分子目录
- `solution/` 集中管理所有 managed .csproj/.sln，整个目录不提交 git
- `solution_native/` 集中管理所有 cmake 项目，整个目录不提交 git
- `il2cpp_dist/` 存放 il2cpp 翻译产出，不提交 git
- `reports/` 存放测试报告，不提交 git
- `.gitignore` 屏蔽以上生成目录

### authority 决策

- Test 执行方式：兼顾 xunit [Fact] + 反射驱动
- Native 流程：这次实现完整 il2cpp 链路（从 managed DLL → native-aot.generated.cpp）
- Patch 独立编译，不引用 src/

### 风险评估摘要

- il2cpp 完整链路集成有技术风险，需要 pipeline 适配
- managed_test 的反射驱动部分需要设计属性发现机制

### 三优先级权衡结论

| 维度 | 结论 |
|------|------|
| P1 性能最优 | native 侧完整 il2cpp，性能无损 |
| P2 架构完美 | 源码/构建分离清晰，目录职责单一 |
| P3 热更适配 | patch 独立 src/patch/，独立编译 |
