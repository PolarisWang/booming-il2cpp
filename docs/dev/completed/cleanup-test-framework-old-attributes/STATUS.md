## 设计摘要

Chaos.TestFramework.Sdk 源码已移除了 8 个旧属性类型（CapabilityFamilyId、BenchmarkSubjectId、BenchmarkRoute、BenchmarkProfile、MethodSubjectId、VerificationRoute、HotUpdateSubjectId、HotUpdateDirection），但：
1. NuGet 包未重建，全局缓存仍包含旧类型
2. `test_code_generator.py` 仍生成这些旧属性

4. `ArithmeticPatch.cs` 是唯一被编译且会 break 的文件
