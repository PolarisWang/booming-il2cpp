## 关键设计决策

- 不为 `Chaos.IL2CPP.HotUpdate` 反向引用 `Chaos.IL2CPP.Interpreter`。这样避免项目循环依赖，`RuntimeManager` 通过 subject-id 级泛型注册与历史快照承接当前 Phase C 行为。
- `AutoBridgeGenerator` 故意限制到 5 类高频签名，复杂签名先通过 `NotSupportedException` 明确暴露，不在 Phase C 内做半成品泛化。
- `perf_dashboard.py` 不是排除所有 benchmark subject，而是仅跳过缺少 baseline/数值指标的项，保留已基线化 `GenericEcho`。
