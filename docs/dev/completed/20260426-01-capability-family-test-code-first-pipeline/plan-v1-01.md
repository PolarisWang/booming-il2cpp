## Phase 4: Pipeline Plugins（2 天）

### 4.1 NativeProofEvaluator

```python
class NativeProofEvaluator:
    gate_code = "native-proof"

    def evaluate(self, family, test_metadata, evidence_bundle):
        # precondition: testCodeStatus != "absent"
        if family.get("testCode", {}).get("testCodeStatus") == "needs-tests":
            return blocked("test code required")

        # check coverage.json
        cov = evidence_bundle.latest_coverage
        if cov.emitted_count > 0 and cov.uncovered_count == 0:
            return passed(progress=100, evidence=cov_paths)
        if cov.emitted_count > 0:
            return in_progress(
                progress=cov.verified_count / cov.emitted_count * 100,
                evidence=cov_paths,
            )
        return pending()
```

### 4.2 ManagedProofEvaluator

从 test run report 获取通过/总测试数。

### 4.3 BenchmarkEvaluator

从 benchmark report 获取达标/总 benchmark 数 + 阈值判断。

### 4.4 Ledger Write-back

Pipeline 执行完后，更新 ledger 的 `verificationGates` 状态。
