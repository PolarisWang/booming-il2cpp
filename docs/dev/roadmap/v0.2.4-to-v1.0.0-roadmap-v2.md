# Chaos IL2CPP 发布路线图 (v2 — 最终版）

> **推进用任务计划** — 纬度：版本模型 / 里程碑次序 / 任务粒度 / 决策门
> 基线：v0.2.4 (2026-09-07) · 目标：Windows GA v1.0.0

---

## 版本模型

```
v0.2.4 ─┬─ M1: GC稳定 ─── v0.2.5 (仅内部修复，不发布)
         │
         ├─ M2: Harness首绿 ─ v0.2.6 (CI/Nightly/质量/报告全自动)
         │
         ├─ M3: CoreLib三轴 ─ v0.3.0 ← 首个内部 feature 里程碑
         │
         ├─ M4: Foundation三轴 ─ v0.4.0
         │
         ├─ M5: 引擎端到端 ── v0.5.0
         │
         └─ M6: Windows GA ── v1.0.0 ← 产品发布
                │
                ├─ M7: Linux GA ── v1.1.0 (post-1.0)
                │
                └─ M8: 移动/主机 ── v1.2.0+ (post-1.0)
```

**核心原则**：
- Gate 驱动，非每步发号 — 每一里程碑的决策门(G0-G7)全绿才推进到下一个
- 第一个 GA = Windows 引擎可接 — 不等 Linux/移动/主机。Linux/Mobile/Console 在 1.1/1.2+ 逐平台追加
- 引擎 IL2CPP 字节级兼容 + PS5 属远期(需厂商合同/NDA)，不阻塞 1.0
