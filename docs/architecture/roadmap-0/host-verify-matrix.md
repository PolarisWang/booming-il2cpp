# Host-Specific Verify Matrix

## Matrix

- Windows host: Windows + Android + Linux (cross-compile/packaging)
- macOS host: macOS + iOS + Linux (cross-compile/packaging)

## Notes

- Linux 在 roadmap-0 范围内以 cross-compile/packaging 能力作为 host-specific verify 目标。
- 移动端目标中，Android 关注真机/模拟启动链路，iOS 关注 compile/link/packaging 链路。
